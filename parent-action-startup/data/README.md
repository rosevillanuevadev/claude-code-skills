# Data Folder

`data/synthetic/` contains fake data used for prototypes, tests, and demos.

`local_data/` at the repository root is gitignored and may be used for private local experiments. Do not put real customer/student data into source control.

Synthetic fixtures should model realistic edge cases:
- multiple children
- multiple schools
- two guardians
- delegated assistant
- one school contact
- unread notice
- overdue action
- absence notice waiting on school
- acknowledged excuse
