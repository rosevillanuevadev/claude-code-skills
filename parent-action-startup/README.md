# Parent Action — Working Project

Working repository for a lightweight parent–school action product.

## Core idea

Busy parents should have one simple place to know what school needs from them and to send formal parent actions back to school.

The product is **not** an SIS, LMS, gradebook, attendance platform, school social network, or general family organizer.

The initial product thesis is:

> Know what school needs from you. Get it done.

The product should work for a parent even when the school has not formally adopted it. School participation should improve the experience, not gate the parent’s value.

## Core directions

**School → Parent**
- notice / letter
- acknowledgment
- consent / response
- requested document or submission

**Parent → School**
- report absence
- send excuse letter
- submit requested document
- formal response

## Product rule

Every item should make one thing obvious:

> Who needs to do something next?

Possible states: `Needs your action`, `Waiting on school`, `Done`.

## Repository rule

This repo is the persistent project brain. Agents must not rely on chat memory. Read `AGENTS.md`, `docs/STATUS.md`, `docs/ROADMAP.md`, and recent ADRs before substantive work. Update the relevant documentation after substantive work.
