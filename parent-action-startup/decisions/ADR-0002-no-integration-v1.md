# ADR-0002 — No required school integrations in V1

## Status
Accepted.

## Decision
Do not require Teams, Google Classroom, SIS, LMS, or roster API integrations for V1.

## Rationale
The product must remain lightweight and globally portable. Integration work can create long implementation cycles and lock product value behind school IT cooperation.

## Consequences
Use manual entry, uploads, email delivery, secure links, and later CSV import. Revisit integrations only after validated demand.
