# Spec 006 — School Workspace

Deferred until parent-side value is proven.

## Goal
Let a school intentionally manage formal parent actions without replacing its SIS/LMS.

## V0.1 features
- school profile
- staff roles
- CSV roster import
- guardian mapping
- create notice
- recipient selection
- action type: Read / Acknowledge / Respond / Submit
- optional due date
- send
- completion/outstanding dashboard
- remind incomplete recipients
- response/submission history

## Hard boundary
No grades, attendance-taking, enrollment, tuition, chat, behavior, or LMS functions.
