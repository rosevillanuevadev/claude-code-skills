# Spec 001 — Parent Action Inbox

## Goal
A parent can open the app and immediately know what requires attention across all children.

## Primary views
- Needs Action
- Waiting on School
- Done

## Each row/card must show
- child
- concise title
- action required
- due date if any
- current owner / next actor
- source indicator

## Required behaviors
- filter by child
- open original source/record
- mark manual action done
- assign to delegate later
- no calendar view required in V0.1

## Acceptance criteria
- parent can understand the next action without opening the original source
- parent can reach the original source within one tap/click
- completed items leave Needs Action immediately
- app does not create ambiguous “read but maybe needs action” states
