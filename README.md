# Claude Code Skills

Rose's personal collection of reusable Claude Code skills. Each skill lives in its own folder
with a single `SKILL.md`.

| Skill | Use for |
|---|---|
| [circumnavigation-distance](circumnavigation-distance/SKILL.md) | Measuring the shortest-swimmable-path distance for an island or loop circumnavigation swim from raw GPX files, and building the public route analysis page for it |

To install a skill locally, copy its folder into `~/.claude/skills/`.
